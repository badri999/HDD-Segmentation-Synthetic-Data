# HDD-Segmentation-Synthetic-Data

This repository provides access information and documentation for the synthetic HDD instance segmentation dataset developed for the paper:

**Fringe Projection Based Vision Pipeline for Autonomous Hard Drive Disassembly**

## Status

The dataset download link is **coming soon**.  
This repository will be updated with the public download link and access instructions once hosting is finalized.

## Overview

This dataset contains synthetic images and annotations generated for hard disk drive (HDD) instance segmentation. It was created to support research on semantic scene understanding for autonomous HDD disassembly, including component localization and fastener detection.

The dataset was developed as part of the vision pipeline presented in the above paper.
